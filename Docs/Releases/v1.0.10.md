# SimCopter Remake v1.0.10 — emergency response and flight stability

This Windows release includes all completed local changes since v1.0.9: quieter
medical dispatches, working street responders, medic triage and retrieval fixes,
safer rooftop exits, bounded responder navigation, stable remote taser aiming,
and air support that waits for your orders.

## What's new

- **Fewer medical alerts.** New medical HUD/radio reports are limited to one
  complete announcement per 60 simulation seconds, including mass casualties.
  All patients and rescue missions remain active; suppressed announcements do
  not build up in a queue.
- **Medics prioritize urgent patients.** Hospital crews unload the most wounded
  living helicopter patients first while keeping separate reservations. Deployed
  medics no longer let an out-of-range casualty hide a reachable injured rioter;
  pickup and return to the landed helicopter are covered by a regression test.
- **Less emergency traffic, useful responders.** Emergency vehicles have a 2%
  chance in ambient traffic choices, with at most one circulating ambient copy
  per service. Dispatch compares available street vehicles and service HQs by
  road travel time. The winning street vehicle becomes the actual responder;
  HQ launches when closer. Busy or disabled vehicles keep their existing state.
- **Safer rooftop exits and posted crews.** Landed exits require support beneath
  the pilot and try nearby safe door positions before refusing an unsafe exit.
  Rooftop personnel check the actual roof geometry while moving, and stranded
  saved personnel can recover to a verified foothold.
- **Bounded responder navigation.** Moving or changing targets no longer bypass
  the pathfinding retry interval. Searches retain their progress and spread
  expensive work across updates, while preserving patient reservations and
  checking paths against current obstacles. This fixes a reproduced source of
  CPU stalls; it is not a measured before/after FPS result for a live flight.
- **Stable remote taser and scope zoom.** The aircraft holds position near a
  clear target, smooths pursuit, and keeps its nose steady while aiming. Mouse
  wheel zoom spans 1x–4x; holding LT uses 4x. Aim sensitivity follows zoom.
  Returning to flight faces the pursued enemy without moving the helicopter.
- **Air support waits for an order.** Graduation makes the helper available at
  base. Use AIR: MISSION or Air: Map Mission to assign each job. Completion,
  recall or an unavailable target returns it to standby. Older automatic saves
  finish loaded deliveries and then wait; explicit assignments survive loading.

## Download and run

Extract `SimCopterRemake-v1.0.10-Windows-x64.zip` completely, then run the root
`SimCopterRemake.exe`. Keep the accompanying folders together. Unreal Editor is
not required. If Windows requests the Visual C++ runtime, run
`Engine/Extras/Redist/en-us/vc_redist.x64.exe`.

The package includes 45 maps, 21 KINV tracks, two drive-in movies and 30 city-tour
soundtracks. Normal play uses Shipping. The optional GPU and performance
diagnostics launchers use the included Development build. Personal saves,
settings, logs, crash captures and PDB symbols are excluded. `BUILD_INFO.json`
records the source commit; `SHA256SUMS.txt` verifies the download.
