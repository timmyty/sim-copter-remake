# SimCopter Remake v1.0.18

City Hall now follows the original SimCity 2000 landmark more closely: stepped
rotunda tiers, a shallow ribbed crown, a narrow lantern, pale stone wings and a
columned entrance. Detailed roofs, edges, six AC units, two rooftop service
structures and clipped entry hedges add detail while using 70.9% fewer triangles
than the previous review model. Window lighting follows the city day/night settings.

- Piers sit close to the water, with clearance adjusted for waves.
- Every water-tower placement uses the improved tank and supports, with a sealed
  neutral-metal lid and no blue roof. Old plain red towers are replaced.
- Catalog Left/Right stays on the aircraft row; Down selects Upgrades or Apache.
- Select/View/Back consistently cycles flight cameras through the actual input
  stack, dismisses persistent tool panels and exits the remote-taser sight.
- Manually dropped police and medics wait at least 15 seconds of gameplay time
  before boarding again, including after the final patient handoff.
- Twenty documentation screenshots retain their original dimensions while
  shrinking from 48.0 MB to 4.52 MB (90.6% smaller). Text-heavy guides remain lossless.

See [appearance, controls and diagnostic details](../CivicAndWaterfrontReview.md).

  GPU crash logging or performance traces.

Save format is unchanged. Existing optional music downloads remain compatible.

## Performance diagnostics

After running `Launch-With-Performance-Diagnostics.cmd`, look under
`%LOCALAPPDATA%\SimCopterRemake\Saved\`:

- `Logs\Performance-Diagnostics.log` for the text log.
- `Profiling\Witness-Performance_<timestamp>.utrace` for Unreal Insights traces.
- `Crashes\` for crash evidence, if a crash generated it.
