# SimCopter Remake v1.0.3 — visible drive-in movies

This fixes the blank theater picture when `hsi` or `Lights, Camera, Action!` plays
movie audio. The movie plane and its black backing now face the parking lot and
render in front of the theater's original screen.

Download the Windows ZIP from the [release](https://github.com/timmyty/sim-copter-remake/releases/tag/v1.0.3),
extract the complete archive, and run `SimCopterRemake.exe`. No Unreal Editor is
required. Keep the adjacent folders together; do not copy an older installation's
executable over the new one. All v1.0.2 maps, drive-in logos, KINV defaults, remembered
station preferences, tracks and movies are included.

The fix was reproduced before the change, then checked by entering both movie
cheats and rendering the actual theater in Sea Cliff. Both pictures were visually
inspected. Editor and Shipping builds and all five targeted movie/placement/minimap
tests passed. The earlier full-suite's two unrelated known failures were not part
of this targeted run. No manual flight or live listening test was performed.

See the [before/after evidence](../DriveInVideoVisibility.md). The ZIP's
`BUILD_INFO.json` identifies the source commit and executable hash, and the release
includes `SHA256SUMS.txt` for the download.
