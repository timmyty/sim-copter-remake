# SimCopter Remake v1.0.5

Download `SimCopterRemake-v1.0.5-Windows-x64.zip`, extract the entire archive, and
run `SimCopterRemake.exe`. Keep all adjacent folders together. Unreal Editor is
not required. If needed, install the included Visual C++ runtime from
`Engine/Extras/Redist/en-us/vc_redist.x64.exe`.

Movie audio now plays locally at **every drive-in theater** in a city. Each
screen has its own positional speaker and distance falloff. Sound returns when
you approach again, pauses with the game, and stops at demolished theaters.
The video remains full width and 75% of the screen height.

Editor and Shipping builds succeeded; all six targeted tests passed. Captured
Windows mixer output confirms HSI at eight theaters before and after switching
movies, distance falloff and return, pause/resume, and independent demolition.
The original bundled movie has a silent audio track, which is preserved.
Actual theater rendering, all-map placement, minimap logos and cheat commands
also passed. No manual flight or physical-speaker listening test was performed.

The ZIP includes required original game data, 21 radio tracks and both movies.
Personal saves/settings and debug symbols are excluded. `SHA256SUMS.txt` verifies
the download; `BUILD_INFO.json` records the source commit and executable hash.
