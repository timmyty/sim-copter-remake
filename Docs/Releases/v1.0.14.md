# SimCopter Remake v1.0.14 — optional game music

Adds optional game soundtrack collections to the radio, with native MP3 playback
and an installer. **959 recordings across 32 collections** are available as
individual game ZIPs or an All-Games bundle. The normal game contains the existing
soundtrack; download only the additional music you want.

Install the full `SimCopterRemake-v1.0.14-Windows-x64.7z`, then extract a music
package and run **Install-Music.cmd**. Choose the game folder, restart the game,
and select a game collection in Radio (Ctrl+R). All numbered All-Games parts must
be downloaded together before extracting `.001` with 7-Zip.

The [music guide](../OptionalMusic.md) contains direct per-game downloads, exact
installation paths, source credits and comparison details. The complete original
[SimEverything archive](https://archive.org/details/SimEverything) is also available
as two preservation parts. Its selected music is integrated into the installable
collections; the complete source archive separately retains all spoken material.

No supplied music was lossily re-encoded, resampled or reduced to mono. Existing
FLAC masters are retained; 52 matching SimCopter source recordings were excluded.
Four Ogg containers were repaired without changing their decoded audio; original
containers are retained. Distinct arrangements and alternate recording lengths
remain labelled. The SimCity 64 FLAC collection includes all 17 tracks.

The matching optional diagnostic overlay is
`SimCopterRemake-v1.0.14-Optional-Development-Windows-x64.7z`. Extract it inside the
full game directory if GPU/performance diagnostics are needed.
