# SimCopter Remake v1.0.14 — optional game music

The v1.0.14 game binaries have been superseded. This page remains the optional
music library; all music downloads below work with v1.0.15 and later.

## REQUIRED — download this to play

**[Download the latest full Windows game](https://github.com/timmyty/sim-copter-remake/releases/latest)**

This is the **only game download required**. It includes the existing soundtrack.
Extract the entire archive and run **SimCopterRemake.exe**. Keep all extracted folders
together. If Windows requests the Visual C++ runtime, run
`Engine/Extras/Redist/en-us/vc_redist.x64.exe`. Unreal Editor is not required.

Everything below is optional. GitHub’s automatic **Source code** downloads are for
developers and do not contain the playable game.

---

**959 recordings across 32 game collections**, about 36 hours. Download selected
packs below **or** the All-Games bundle. Each pack includes **Install-Music.cmd**:
extract completely, run it, select the installed game folder, then restart and open
**Radio (Ctrl+R)**. Each game appears as its own collection, including games sharing a ZIP.

## OPTIONAL — SimEverything original preservation archive

**Preserves the complete original SimEverything collection: 854 MP3s and cover
artwork, including game music, radio commercials and news, with original filenames.**
This is the unchanged source archive from [SimEverything on Internet Archive](https://archive.org/details/SimEverything).

**2.58 GB total; download both parts:** [Part 1 of 2](https://github.com/timmyty/sim-copter-remake/releases/download/v1.0.14/SimEverything-Original-Preservation.7z.001) + [Part 2 of 2](https://github.com/timmyty/sim-copter-remake/releases/download/v1.0.14/SimEverything-Original-Preservation.7z.002).

Keep both parts together and extract `.001` with 7-Zip. This archival download has
**no installer**. To add the selected SimEverything music to SimCopter automatically,
choose the installable music packs or All-Games bundle above.
