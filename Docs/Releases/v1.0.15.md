# SimCopter Remake v1.0.15 — live lighting and clean city tours

Warehouse/hangar materials, smoke and other effects now refresh their brightness
as the time of day changes in Photo Mode and during normal play. Paused camera
exposure can also adapt while the simulation remains frozen. City tours no longer
display the gameplay **PAUSED** overlay.

## Downloads

- **Required:** [Full Windows x64 game](https://github.com/timmyty/sim-copter-remake/releases/download/v1.0.15/SimCopterRemake-v1.0.15-Windows-x64.7z). Extract the entire archive and run `SimCopterRemake.exe`.
- **Optional diagnostics:** [Matching Development overlay](https://github.com/timmyty/sim-copter-remake/releases/download/v1.0.15/SimCopterRemake-v1.0.15-Optional-Development-Windows-x64.7z). Extract its contents inside the full game's folder.
- **Optional music:** [Music library and installation guide](https://github.com/timmyty/sim-copter-remake/blob/v1.0.15/Docs/OptionalMusic.md). All existing v1.0.14 music packs work with this release; already installed packs do not need downloading again.
- [SHA-256 checksums](https://github.com/timmyty/sim-copter-remake/releases/download/v1.0.15/SHA256SUMS.txt).

## Changes

- A shared presentation update keeps exposure-scaled materials and hangar fill
  lights current even when their actors are paused. Time-of-day seeks refresh
  these bindings immediately.
- The same path covers smoke, fire, pedestrian cards, particles, flashing lights,
  dispatch and recovery markers, baseball scoreboards, drive-in screens and
  handheld/helicopter taser effects. Authored brightness scales and off states
  are preserved.
- Sun/moon selection follows the light currently illuminating the ground instead
  of retaining a daylight choice after sunset.
- Paused eye adaptation receives real frame time without advancing the game clock.
- The ordinary pause display remains available during gameplay, while the city
  tour hides it.

## Validation

Built and tested from the publication checkout. Regression coverage includes
paused day/night/day brightness, unpaused updates, moon selection, frozen game
time and the renderer's exposure timing. An offscreen D3D12 fixture checks the
actual hangar and smoke materials. This is a synthetic scene; no interactive
playthrough or reproduction of the user's exact city is claimed.

Editor, Shipping and Development builds passed. All **524 distinct automation
cases** have passing final results. One settings-persistence case needed a rerun
with config saving enabled in the isolated test profile; the initial multiprocess
runner suppressed disk writes. The offscreen lighting case passed, and both
packaged executables passed separate hidden 30-second startup checks.

[Detailed validation receipt](https://github.com/timmyty/sim-copter-remake/blob/v1.0.15/Docs/validation/WindowsRelease115Results.json).

Older game downloads are being retired to reduce storage. The v1.0.14 release
remains the optional music library so existing music URLs keep working; source
history and version tags are retained.
