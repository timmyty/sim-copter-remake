# SimCopter Remake v1.0.2 — Windows x64

Download the Windows ZIP from the [GitHub release](https://github.com/timmyty/sim-copter-remake/releases/tag/v1.0.2).
Extract the entire archive, open the extracted folder, and run `SimCopterRemake.exe`.
Keep the adjacent folders together. Unreal Editor and a source checkout are not
required. If a Visual C++ runtime is missing, run the included
`Engine/Extras/Redist/en-us/vc_redist.x64.exe` and try again.

## Changes

- All 45 bundled maps have drive-in theaters. New lots use clear, dry terrain with
  level foundations and limited grading that preserves neighboring roads and buildings.
- Small cinema logos identify theaters on the minimap at every zoom level.
- Fresh radio preferences default to KINV. Subsequent launches restore the last
  station selected, including after station-list reordering. Existing saved choices
  and volume settings are retained.
- Includes the previously published gameplay fork improvements, all 21 KINV tracks,
  both drive-in movies, required city data, cooked content and runtime dependencies.

## Validation

Editor and Shipping builds succeeded. Of 320 headless automation tests, 318 passed
and two previously documented tests failed (`ReferenceCity` fixture altitude samples
and `FlapLayout` equipment-mask expectation). The separate offscreen real-city movie
playback test passed. All 45 map placements and the minimap logos were checked.

The package is assembled from the validated installation, with every NonUFS manifest
entry present and runtime copies verified by SHA-256. It excludes personal saves,
settings and debug symbols. The downloadable `SHA256SUMS.txt` verifies the ZIP.
`BUILD_INFO.json` inside the ZIP identifies the source commit and executable hash.

No foreground flight or listening test was performed. Custom maps that have no
safe theater site are left intact instead of being forcibly rebuilt. Full evidence:
[validation](../ForkValidation.md) and [drive-in/radio results](../validation/DriveInRadioResults.json).
