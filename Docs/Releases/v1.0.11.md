# SimCopter Remake v1.0.11 — lossless music, Photo Mode and custom-city progression

This Windows release includes all completed work since v1.0.10, including the changes from the custom-city/Photo Mode and saved-game browser tasks.

## What's new

- **Lossless original music.** Fifteen verified songs now use the supplied 44.1 kHz, 16-bit stereo FLAC masters: two jazz tracks, all six rock tracks, all six techno tracks and the hangar theme. Each recording is stored once and shared by its genre station and KMIX. The corresponding 29 low-quality WAV copies are omitted from the package. Unmatched songs, KINV, city-tour audio, DJs, commercials and effects are preserved. Some masters are longer edits of the same song. Custom recordings with reused original filenames are preserved.
- **Custom-city progression.** Jobs unlock at best scores of 0, 500, 1,500 and 3,000; losing points does not remove an earned stage. Rescue and incident eligibility also checks aircraft equipment. Riots require an upgraded cabin and loaded tear gas. New saves remember the best score, and older saves remain supported.
- **Rescues throughout custom cities.** The initial scan covers the full 128×128 map. Rooftop rescues require suitable tall roofs; boat rescues require open water with room away from shore. Sites no longer depend on distance from the hangar or current camera, and active missions avoid sharing a rescue site.
- **Passenger parties fit the aircraft.** Medical jobs reserve a seat for a medic. Other transport and rescue groups fit the current helicopter's passenger capacity, including career jobs, boat/train rescues and plane survivors. Existing active or saved parties are retained.
- **Photo Mode.** Use Esc → Photo Mode or Ctrl+P to pause, hide the HUD and frame a shot with a free camera. F12 captures a screenshot without the HUD, cursor or photo panel. WASD, Space/Ctrl, RMB + mouse and the wheel control the camera; H toggles its controls. Exiting restores the previous camera, input, HUD and lighting.
- **Day/night controls.** Options → Gameplay provides a live day/night slider. Photo Mode has a temporary lighting adjustment that restores the gameplay clock when you leave.
- **Cleaner help and controls.** F1 toggles the expanded keyboard help, including tool instructions; R3+L3 remains the controller shortcut. Shift toggles Turbo on foot or helicopter boost, sharing the L3 state while preserving Shift+F2–F5 responder recalls. The cursor hides after ten seconds without mouse activity and returns when moved or clicked.
- **Revised pause menus.** Career and custom-game menus include Photo Mode and a hidden Cheat Codes plate immediately above Continue, revealed by hovering or moving Up. Resized original artwork supplies the menu plates and lever strip.
- **Browse for cities and saves.** Browse opens the native Windows file dialog for `.sc2` cities and remake `.sav` files in any folder, even when the local save list is empty. Career and user saves retain their mode checks. New user saves preserve external city paths, with adjacent-city and standard-folder fallbacks; older saves still load. Cancelling or an invalid file preserves the current picker/session.

Details: [lossless music](../HighQualityMusic.md), [custom cities, Photo Mode and file browsing](../CustomCityProgressionAndPhotoMode.md), and [controller support](../ControllerSupport.md). Earlier releases' changes remain included.

## Download and run

Download `SimCopterRemake-v1.0.11-Windows-x64.7z`, extract the entire archive (using 7-Zip if needed), then run the root `SimCopterRemake.exe`. Keep the accompanying folders together. The FLAC soundtrack is already included; no separate music download is needed. Unreal Editor is not required. If Windows requests the Visual C++ runtime, run `Engine/Extras/Redist/en-us/vc_redist.x64.exe`.

This release uses 7z compression to keep the complete game under GitHub's 2 GiB per-file limit.

The package includes 45 maps, 21 KINV songs, two drive-in movies, 30 city-tour soundtracks and the 15 shared lossless masters. Normal play uses Shipping; the optional GPU/performance diagnostics launchers use the included Development build. Personal saves, settings, logs, crash captures and PDB symbols are excluded. `BUILD_INFO.json` records the source commit and `SHA256SUMS.txt` verifies the download.
