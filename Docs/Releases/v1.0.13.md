# SimCopter Remake v1.0.13 — smaller KINV music and optional diagnostics

All 21 KINV songs now use compact stereo Ogg Vorbis at a nominal 128 kbps. Their
installed size drops from **849.10 MiB to 72.65 MiB**, a **91.4% reduction**.
This intentionally uses lossy audio compression while retaining every full song,
stereo playback and the 44.1 kHz sample rate. The fifteen original-game lossless
FLAC masters are unchanged.

KINV keeps its song order, radio-menu selection, pause, seeking, volume and saved
playback position. Older saved WAV filenames resolve to the corresponding Ogg
song. Compressed decoding runs on a cancellable worker, and tuning away or
turning the radio off discards pending playback. Upgrading over old WAVs does
not duplicate songs in the playlist.

## Downloads

- **Normal game:** `SimCopterRemake-v1.0.13-Windows-x64.7z`. Extract the complete
  archive and run the root `SimCopterRemake.exe`. This contains the Shipping
  build, all 21 KINV songs, the original lossless soundtrack and the existing
  maps, movies and other game content. Unreal Editor is not required.
- **Optional diagnostics:** `SimCopterRemake-v1.0.13-Optional-Development-Windows-x64.7z`.
  Download only when GPU/performance diagnostics are needed. It requires the
  full v1.0.13 game. Extract its **contents inside the extracted game folder**,
  beside the root `SimCopterRemake.exe`, merging the Engine and SimCopterRemake
  folders. It adds the Development executable, its extra runtime DLL and
  `Launch-With-GPU-Diagnostics.cmd` / `Launch-With-Performance-Diagnostics.cmd`.
  Normal play still uses the root launcher.
- `SHA256SUMS.txt` verifies both archives. Their build-information files identify
  the matching source commit.

For the smaller installed size, extract the normal game into a fresh folder:
overwriting an old installation does not remove its old WAVs or Development
executable. Existing user-profile saves/settings remain available. Copy any
custom files you placed inside an old installation separately.

The Development executable and diagnostic launchers are no longer bundled in
the normal download. Gameplay and the other soundtrack/media choices are unchanged.

## Validation

Editor, Shipping and Development builds succeeded from the isolated publication checkout. All 522 distinct automation cases have passing final results (482 clean, 40 with warnings). The full sweep passed 520/522; after restoring missing generated editor assets, the affected ServicePosts tests all passed without code or test changes. No cases remain failed or unrun. Both packaged Shipping and the optional Development overlay survived separate hidden 30-second startups with isolated profiles. All 21 complete Ogg songs were decoded by both FFmpeg and Unreal. Regression coverage includes saved WAV-to-Ogg position migration, duplicate prevention, full song duration, stereo format, paused seeking, cancellation, mute and playlist order. [Detailed results](../validation/WindowsRelease113Results.json).

No interactive gameplay, physical-controller or manual listening check is claimed.
The previously reported witness-photo slowdown and GPU compute crash remain
unresolved; this release changes music encoding and download packaging.
