# SimCopter Remake v1.0.4 — larger drive-in picture

Drive-in movies now stretch across the screen's full width and **three-quarters of
its height**, centered vertically. The complete frame stays visible without
cropping. HSI is one-third taller than in v1.0.3. All movie commands use the same
picture area; any borders encoded in the source video remain visible.

Download the Windows ZIP from the [release](https://github.com/timmyty/sim-copter-remake/releases/tag/v1.0.4),
extract it completely, and run `SimCopterRemake.exe`. Keep the adjacent folders
together. No Unreal Editor is needed. All previous gameplay improvements, maps,
KINV tracks and drive-in movies are included.

Editor and Shipping builds and all five targeted tests passed. The rendering test
enters both movie cheats and checks actual theater geometry, full source-frame
coverage, requested dimensions and visible video pixels. The HSI frame was visually
inspected. No manual flight or listening test was performed. The earlier full
suite's two unrelated known failures were outside this targeted run.

See [picture sizing and validation](../DriveInPictureSizing.md). The release includes
`SHA256SUMS.txt`; the ZIP's `BUILD_INFO.json` identifies the source commit and
executable hash.
