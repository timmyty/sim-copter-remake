# SimCopter Remake v1.0.6 — NPC identities and gameplay update

Download **SimCopterRemake-v1.0.6-Windows-x64.zip** from the release Assets,
extract the entire ZIP, and run **SimCopterRemake.exe**. Keep all adjacent folders
together. Unreal Editor is not required. If the Visual C++ runtime is missing,
run the included `Engine/Extras/Redist/en-us/vc_redist.x64.exe`.

## Added since v1.0.5

- Matching NPC bodies, hair, clothing, heads and passenger portraits across
  walking and helicopter views; the actual pilot appears in every aircraft.
- Animated medic-care portraits while living patients are aboard, retaining
  original flight reactions and the original patient-survival benefit.
- Thirty city-specific flyovers with original soundtracks, close aircraft
  passes and animated wind turbines.
- Shoulder-camera taser aiming with a hand-mounted weapon, a pause-menu cheat
  guide, restored cockpit wiring, remembered radio tuning and aircraft selection.
- Safer outdoor medical calls, helper-aircraft operations, passenger handoffs
  and traffic around parked helicopters; fewer repeated fire reports and larger,
  spaced victory bands.
- Airplane pitch/throttle controls, spinning propellers, retractable gear and
  speed/gear controls; expanded Apache vehicle/building damage and rescueable
  injuries from the Radioactivity cheat.
- The enlarged original drive-in movie, cockpit wind-indicator removal, and all
  prior fork additions, including police tasers, recovery equipment, parachuting,
  21 KINV radio tracks, two drive-in movies and 45 bundled maps.
- An expanded README explaining the fork's gameplay additions and departures
  from the original game.

## Package and validation

This package uses the latest verified Shipping executable. All **903 loose
runtime dependencies** are present, including **30 flyover soundtracks**. The
launcher passed a hidden, isolated 30-second startup check. Every runtime copy
and every ZIP entry is hash-verified. Personal saves/settings, logs and debug
symbols are excluded. `SHA256SUMS.txt` verifies the download; `BUILD_INFO.json`
inside the ZIP identifies its source revision and executable hash.

Both builds and **18 focused NPC/passenger/medical/save tests**, plus the
offscreen character/cabin test, passed for the latest gameplay changes. The
earlier combined update passed **377/379** headless tests, all **37 graphics
checks** and its audio mixer test. The two existing failures concern the
ReferenceCity fixture and FlapLayout expectation. Those earlier full-suite
results were not rerun for this packaging-only update. No manual flight or
physical-speaker listening test was performed.

[Validation details](https://github.com/timmyty/sim-copter-remake/blob/v1.0.6/Docs/ForkValidation.md).
