# SimCopter Remake v1.0.12 — controller navigation, medical crew and cockpit improvements

This Windows release includes all completed changes since v1.0.11.

## What's new

- **Continuous controller browsing in the hangar.** Selecting a helicopter keeps the highlight on its catalog tab. Move left or right to the neighboring helicopter without returning through the transaction controls.
- **Medics prioritize their rescue work.** Manually deployed crew search for nearby patients even when they step onto a hospital tile. A returning medic checks again for available patients, and leaves cabin space for patients another medic is retrieving.
- **Medics disembark with patients.** When you let a medic out of a landed helicopter, they take an available onboard patient, carry them away and set them down through the existing medical handoff. Two medics take different patients. Existing wounded-first triage, patient identity and delivery accounting are preserved. An airborne crew drop leaves the patient safely aboard.
- **Full cockpit radio menu.** Ctrl+R, a double-click on the radio, or R3 + View/Touchpad opens a paused-flight panel with stations and numbered tracks, commercials, DJ clips and jingles. Select an exact item, pause, skip tracks, seek, adjust volume and see elapsed/total time while the radio continues playing. KINV retains its album order and resume behavior.
- **Controller radio navigation.** D-pad or left stick moves between controls; A enters a list or slider, directions browse or adjust it, and B leaves it before closing the panel. Y pauses, LB/RB changes tracks, and LT/RT skips ten seconds. Menu navigation prefers controls in the same visual row or column.
- **Remote-taser autopilot switch.** The revised remote panel has a saved ON/OFF switch. OFF keeps manual hover, aiming and firing while disabling automatic pursuit, pickup and recovery reconnection. Older saves default to ON.
- **Nearest-hospital map guide.** Selecting an active medical mission shows a white guide to the nearest hospital and a red pickup guide while patients remain. The guide updates as you move; any hospital still accepts the patient.
- **Turbo status and cleaner help.** Sprint is now named Turbo. The minimap has a shared red ON/dim OFF lamp, switch and status for keyboard and controller. A silver header shows F1 or L3 + R3 help shortcuts; the stick chord works in either order. Redundant collapsed help, on-foot Turbo and parachute status text are removed without changing those controls.
- **Saved bucket/harness correction.** Pilot recovery now keeps the selected tool and displayed attachment synchronized. Loading an older affected save repairs a cached harness display when Bucket was actually selected.
- **Empty mission-panel correction.** Returning from Photo Mode, replay or other HUD transitions no longer exposes an empty mission-message rectangle.
- **Automation baseline repaired.** The two longstanding terrain-fixture and equipment-mask test failures have been corrected while retaining their coverage.

Details: [medical crew and catalog fixes](../memory/hangar-medic-deployment.md), [radio controls](../RadioMenu.md), [Turbo HUD](../TurboHud.md), [remote taser](../EnergyTaserAndFreeAim.md), and [controller support](../ControllerSupport.md). All earlier release features remain included.

## Download and run

Download `SimCopterRemake-v1.0.12-Windows-x64.7z`, extract the entire archive with 7-Zip, then run the root `SimCopterRemake.exe`. Keep its accompanying folders together. Unreal Editor is not required. If Windows requests the Visual C++ runtime, run `Engine/Extras/Redist/en-us/vc_redist.x64.exe`.

The package includes 45 maps, 21 KINV songs, two drive-in movies, 30 city-tour soundtracks and 15 shared lossless original music masters. Normal play uses Shipping; optional diagnostic launchers use the included Development build. Personal saves, settings, logs, crash captures and PDB symbols are excluded. `BUILD_INFO.json` identifies the source commit and `SHA256SUMS.txt` verifies the download.
